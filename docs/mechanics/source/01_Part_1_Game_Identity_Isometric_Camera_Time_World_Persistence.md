# Last Light — Part 1: Game Identity, Isometric Camera, Time & World Persistence

Primary Platform: iOS / Mobile. Offline-first, single-player survival simulation with 2:1 dimetric isometric projection (64x32px tiles, Z-0 to Z-8), Canonical World Clock (60 real min = 24 in-game hours, 20x sleep acceleration), Spatial Grid Partitioning (300x300 cells, 10x10 chunks), Utility Shutoffs (0-30 days), World Erosion (100-day curve), Accountable Populations, Meta-Events, and Permadeath.
